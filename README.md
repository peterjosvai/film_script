
# film_script (format) converter
![fsc-convert](images/fsc-convert.svg)


**filmscript-conv** is a simple converter application, written in Python.

It has a command line and a UI version (based on PyQt) (the next version will be GTK3).

It converts **film_script markdown** to: 

+ XML and HTML5
+ Fountain markdown format  
+ Markdown for Writer (to work in Writer, using a simple template)
